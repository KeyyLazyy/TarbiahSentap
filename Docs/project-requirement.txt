1.

Project Overview
Your team is required to develop a secure e-commerce system using a Client–Server Architecture.
The system must demonstrate:
 Secure API communication
 System integration (Frontend ↔ Backend ↔ External API)
 Data conversion (JSON → CSV/XML)

2.

System Architecture
You must build:
a. Backend (API Server)
 Handles business logic & security
 Provides REST API endpoints
b. Frontend (Web Client)
 Calls backend using HTTP
 Displays data to users
*Both MUST be fully separated (decoupled)

3.

Core Functional Requirements
a. Authentication & Security (MANDATORY)
i. JWT-based login system
ii. Password hashing (bcrypt or equivalent)
iii. Role-Based Access Control (RBAC): Customer / Administrator
b. Core API (CRUD)
c. Integration System
i. External API Integration
1. Fetch data from public API (e.g., weather API)
2. Convert response
ii. Payment Webhook Simulation
1. Simulate payment gateway callback
iii. Data Conversion
